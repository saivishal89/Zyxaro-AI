## Overview

**ZARAKI AI** is a private, local-first AI research assistant. It connects directly from your browser to any OpenAI-compatible API — your keys stay in your browser's localStorage and are never sent to any server other than the AI provider you choose.

**Key principles:**
- No account required
- No data leaves your device (except to your chosen AI providers)
- Works with 18 different AI providers simultaneously
- All history, notes, and settings stored locally in your browser

---

## Getting Started

1. Open the app — it launches in **Simulation Mode** by default (no API key needed to explore the UI)
2. Click **⚙ Config** in the top-right header
3. Select one or more AI providers using the provider buttons
4. Paste your API key for each selected provider
5. Click **Save Config**
6. Start chatting — the simulation mode banner disappears once a real provider is active

## Chat Features

### Sending a Message
- Type in the input box at the bottom and press **Enter** or click **SEND ▶**
- Press **Shift + Enter** to add a new line without sending
- Messages auto-scroll to the latest reply

### Topic Auto-Detection
Every message is automatically classified into a research tag displayed on the AI reply:

| Tag | Keywords detected |
|-----|------------------|
| SCIENCE | physics, chemistry, biology, quantum, DNA, space, galaxy |
| TECH | AI, ML, software, code, programming, computer, cyber |
| HISTORY | history, ancient, war, empire, century, revolution |
| FINANCE | finance, stock, market, crypto, bitcoin, investment |
| HEALTH | health, medical, medicine, disease, brain, treatment |
| DATA | data, scraping, web, proxy, crawl, extract |
| RESEARCH | everything else |

### AI Response Style
ZARAKI AI is configured with a strict system prompt:
- Always leads with a **1-2 line TL;DR**
- Uses **bullet points** and short paragraphs
- **Bolds key terms**
- Maximum 5-7 bullets per section
- Concise, information-dense responses

### Multi-Provider Parallel Calling
If you enable multiple providers in Config, ZARAKI sends your message to **all of them simultaneously** and shows each response separately — great for comparing models side by side.

## Image Generation

Type `/image [your prompt]` in the chat to generate an image.

**Example:**
```
/image a cyberpunk city at night with neon lights
```

- Powered by **Pollinations AI** — completely free, no API key required
- Generates at **1024 × 1024** resolution
- Random seed used each time for variety
- Image appears inline in the chat
- Works in both Simulation Mode and live provider mode

|--------|---------|-----------|

| 🖼️ Image | image/* | Attaches for context |

| 📝 Word | .doc, .docx, .txt | Reads text |
| 📊 Excel | .xlsx, .xls, .csv | Reads data |
| 📑 PPT | .ppt, .pptx | Reads structure |
| 🔗 Drive | .json, .txt | Reads local JSON/text |
| 💾 Export | — | Downloads full chat as JSON |

**Notes:**
- Text files (.txt, .md, .csv) are read as plain text
- Other files are read as base64 data URLs
- Maximum ~8,000 characters of file content sent per file
- Multiple files can be attached per message
- Attached file names are shown as chips above the input

## Notes System

The sidebar **Notes** tab stores research snippets you want to keep.

### Saving a Note
- Hover over any AI message → click the **Note** button in the export row
- The note is saved instantly and the sidebar switches to Notes view
- Note title = first 45 characters of the message

### Managing Notes
- Click the **×** on any note card to delete it
- Notes are stored permanently in localStorage until deleted or Burn All is used
- Notes panel shows the date/time each note was saved

## Session Management

The sidebar **History** tab shows all chat sessions.

### Sessions
- Up to **20 sessions** are stored (oldest removed when limit is reached)
- Sessions auto-title from your first message (first 45 characters)
- Click any session in the sidebar to switch to it
- Click **×** on a session to delete it (a fresh session is created if all are deleted)

### New Session
- Click **+ New Session** at the top of the sidebar
- Starts a fresh, empty chat with no history sent to the AI

## Document Export

Every AI message has export buttons that appear on hover. You can export any response as:

| Format | Output |
|--------|--------|
| **Note** | Saves to your Notes tab |
| **PPT** | Downloads a .pptx PowerPoint presentation |
| **DOC** | Downloads a .doc Word document |
| **PDF** | Opens a print dialog for PDF saving |

### How PPT Export Works
- Parses markdown headings (`##`) into individual slides
- Each `##` heading becomes a slide title
- Bullet points (`-`) become slide content bullets
- Dark blue theme matching ZARAKI's brand (`#03081A` background, `#60A5FA` titles)
- Title slide added automatically with ZARAKI branding
- Maximum 15 content slides

### How DOC Export Works
- Converts markdown to Word-compatible HTML
- Styled with Calibri font, professional heading hierarchy
- Includes "Generated by ZARAKI AI" footer
- File opens in Microsoft Word or Google Docs

### Global Export (Header)
Click **⤴ Export** in the header to download **all your sessions and notes** as a single JSON file — use this to back up your data or transfer to another device.

## Voice Features

### Voice Input (Mic Button 🎤)
- Click the **🎤** button next to SEND in the input bar
- Speak your question — it transcribes automatically
- The mic turns red while listening
- Transcribed text is inserted into the input box
- Press SEND or Enter to send it
- **Requires:** A browser that supports the Web Speech API (Chrome, Edge, Safari)

### Read Aloud (TTS)
- Click the ▶ icon on any AI message to hear it read aloud
- Markdown symbols are stripped before speaking (no "hashtag" or "asterisk" in audio)
- Click again to stop mid-playback
- **Requires:** A browser with SpeechSynthesis API support (all modern browsers)

## Config Panel

Click **⚙ Config** to open the settings panel.

### Provider Selection
- Toggle providers on/off using the provider buttons
- A provider is only active if it's toggled ON and has an API key entered

### API Keys
- Enter your key for each provider in its field
- Click the eye icon (👁) to show/hide the key
- Keys are saved to localStorage with the prefix `zrk_k_<provider>`
- Clearing a key and saving removes it from storage

### Custom Provider Fields
When CUSTOM URL is selected, two extra fields appear:
- **Endpoint URL** — full URL to your chat completions endpoint
- **Model name** — the model identifier to send in the request body

### Saving Config
- Click **Save Config** to apply all changes
- A toast confirms which providers are now active
- Any provider toggled ON but missing a key is automatically dropped

## Technical Details

### Stack
- **Framework:** React 18 + Vite
- **Language:** TypeScript (strict mode)
- **Styling:** Inline styles + CSS-in-JS (`<style>` injection)
- **Markdown:** `marked` v4.3.0 (synchronous parse, GFM + line breaks)
- **PPT Export:** `pptxgenjs`
- **Fonts:** Orbitron (titles), Exo 2 (body) via Google Fonts
- **Background:** Animated HTML5 Canvas — 280 twinkling stars + 5 drifting nebulae
- **Thinking animation:** Canvas-based atomic particle simulation (nucleus + electron shells)

### AI API Format
All providers (except Anthropic's native format) use the OpenAI Chat Completions format:

```json
POST <endpoint>
Authorization: Bearer <key>
Content-Type: application/json

{
  "model": "<model>",
  "messages": [
    { "role": "system", "content": "..." },
    { "role": "user", "content": "..." },
    { "role": "assistant", "content": "..." }
  ],
  "temperature": 0.7,
  "max_tokens": 2048,
  "stream": false
}
```

### Image Generation API
```
GET https://image.pollinations.ai/prompt/<encoded-prompt>
  ?width=1024&height=1024&nologo=true&seed=<random>
```
No authentication required.
